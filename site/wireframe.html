The idea

On this page, the 24-part RAR set that deletes itself as it unpacks becomes the sentence, the progress bar and the page’s one live thing.

Direction dealt by taste-skill: “The sentence is the layout”, seed 514656895, with the app’s own palette and type kept. A competitor (WinRAR, 7-Zip) can’t print this page: none of them deletes parts as they go.

The argument, one claim per section

  1. 1 Hero. It unpacks huge games on a nearly full drive. Proof: the live space chips, the running app.
  2. 2 How it works. Space comes back part by part. Proof: drag the job and watch both drives.
  3. 3 Safety. Nothing is deleted until it’s safe. Proof: verify, flush, resume, the confirm dialog.
  4. 4 Explorer. Start from any part with a right-click. Proof: type a file name, see what it does.
  5. 5 CLI. Scripts and AI agents can drive it. Proof: a real terminal session.
  6. 6 Requirements. 12 MB and nothing else to hunt for. Proof: the requirements table.
  7. 7 FAQ. The six worries before pressing start, SmartScreen first.
  8. 8 Download. One sentence with the choice in it, plus the SHA-256.
  9. 9 Footer. The way to reach the maker, set as the headline.

Rules it follows

  • What it is, for whom and the download in the first screen.
  • One primary action, same name everywhere.
  • Headlines two lines or fewer at every width.
  • No invented reviews, logos or user counts.
  • Unsigned beta stated up front, with a checksum.
  • No eyebrow labels, gradients, glass or icon card grids.

3 SafetyComposition: paragraph with picture words

Claim: nothing is deleted until it’s safe. Deleting someone’s 47 GB download is the real fear, so trust is built here, not with badges.

Desktop 1440

Nothing goes until it’s safe

Every part’s checksum is tested on before a byte is written. A part is deleted only after its files are flushed ▮▮▯▯ to disk. Stop halfway and it resumes Resume from the parts that are left.

App screenshot: “Delete parts while extracting?” confirm dialog with the tick box

Early mode frees each part as soon as it is read, so it needs less room. If that run stops, the file being extracted can be lost, so it asks for its own tick first.

Output never overwrites anything: if Game exists, you get Game (2). Passwords go over stdin, never onto a command line.

5 CLI for scripts and agentsComposition: statement left, proof right

Claim: the app is one caller of a plain engine that scripts and AI agents can drive safely.

Desktop 1440

Scripts and agents welcome

The app is one caller of a plain command-line engine. Every input is a flag and nothing ever prompts. With --json, the last line is always the result, carrying the exact command to run next.

python cli.py scan D:\Downloads python cli.py rar extract Game.part1.rar --delete --dry-run python cli.py rar extract Game.part1.rar --delete --yes --background python cli.py jobs wait --timeout 60

Deleting needs --yes. Without it the engine stops with exit code 6 and prints the plan.

Research behind it

  • Value, audience and one dominant action above the fold; aim for the purpose readable in about five seconds. Codivox, Koji five-second test guide
  • Developer tools: show real output and supported environments rather than logos. DEV Community
  • Unsigned Windows exes: explain SmartScreen before users meet it, publish SHA-256 and the PowerShell check, link the source. McpManager guide, SystemManager discussion
  • Dark interfaces: 4.5:1 for text, 3:1 for controls, avoid pure black. Accessibility Checker
